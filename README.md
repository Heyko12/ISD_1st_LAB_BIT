# Обновление решения:

В этой ветке я внесла следующие изменения в свой скрипт:

1) Теперь файл-флаг пишется в директорию, из-под которой запускается скрипт - в ней создается папка tmp, куда записывается pid

2) Соответственно, права супер-пользователя теперь не нужны, удалила логику требования супер-прав у пользователя

3) Параметризовала функцию monitor() чтобы на каждой итерации внесения изменения в файл иметь возможность подменить название на новое, более актуальное

4) Вынесла логику по созданию файла и первичному его заполнению в отдельную функцию - create_monitor_file(), ее также параметризовала, чтобы определять на месте новое название для создаваемого файла

5) В цикле внутри функции daemon_loop() теперь таскаю переменную cur_date, которую обновляю из-под функции check_if_recreation_needed_and_return_new_date() каждый раз, задача которой - проверять переданную дату и сверять с текущей, в случае неравенства возвращать более актуальную и создавать новый файл вызовом create_monitor_file()
